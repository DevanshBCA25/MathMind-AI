# MathMind AI Deployment

## Local

```bash
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py              # http://localhost:7860
```

## Docker

```bash
docker compose up --build   # http://localhost:7860
```
