# 🧠 MathMind-AI

MathMind-AI is an AI-powered mathematical reasoning and learning assistant designed to solve, explain, analyze, and visualize mathematical problems.

The system combines:

- Mathematical computation
- Symbolic mathematics
- AI/LLM reasoning
- RAG (Retrieval-Augmented Generation)
- Multi-agent reasoning
- Computer Vision
- OCR
- Analytics and evaluation
- Interactive Streamlit UI

---

# 🚀 Features

## 1. Basic Calculator

Supports:

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulo
- Safe expression evaluation

## 2. Scientific Calculator

Supports:

- Trigonometric functions
- Logarithms

## 9. OCR

# 🤖 AI / LLM System

MathMind-AI supports multiple LLM providers.

Supported providers:

- Gemini
- OpenAI
- Groq
- Ollama
